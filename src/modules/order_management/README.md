# Модуль управления заказами

## Обзор

Модуль управления заказами с профессиональным компактным дизайном, поддерживающий два типа производства:
- **Серийное производство** - создание заказов с использованием справочника упаковок
- **Индивидуальное производство** - создание заказов с уникальными требованиями через загрузку Excel файлов

## Компоненты

### ProductionTypeSwitch (обновлен)

Компактный переключатель между типами производства.

**Особенности:**
- Минимальный размер
- Четкие иконки
- Активное состояние с подсветкой
- Адаптивный для мобильных устройств

### SeriesOrderCreation (новый)

Профессиональная компактная форма для серийного производства.

**Особенности:**
- Компактная таблица заказов с основной информацией
- Встроенный поиск и фильтрация по статусам
- Прогресс-бар для каждого заказа
- Быстрые действия (просмотр, редактирование, утверждение, удаление)
- Модальное окно создания заказа с 3 полями + выбор упаковок
- Поиск по упаковкам в модальном окне
- Компактная таблица упаковок с количеством

**Интерфейс:**
```tsx
<SeriesOrderCreation onBack={() => void} />
```

### CustomOrderCreation (обновлен)

Компактная форма для индивидуального производства.

**Особенности:**
- Горизонтальное расположение 3 полей в одну строку
- Компактная область загрузки файла
- Минимальные отступы
- Четкая визуальная иерархия

**Интерфейс:**
```tsx
<CustomOrderCreation onBack={() => void} />
```

## Дизайн-система

### Размеры и отступы
- **Заголовки**: 20px (вместо 28px)
- **Текст**: 13px (вместо 15px)
- **Кнопки**: padding 8-10px (вместо 14-16px)
- **Отступы между элементами**: 12-16px (вместо 20-24px)
- **Иконки**: 16-24px (вместо 32-40px)

### Цветовая схема
- **Основной акцент**: #1890ff (синий)
- **Успех**: #52c41a (зеленый)
- **Ошибка**: #ff4d4f (красный)
- **Предупреждение**: #ffc107 (оранжевый)
- **Фон**: rgba(255, 255, 255, 0.05-0.1)
- **Границы**: rgba(255, 255, 255, 0.1-0.15)

### Статусы заказов
- **Предварительный**: #ffc107 (желтый)
- **Утвержден**: #4caf50 (зеленый)
- **Разрешен к запуску**: #2196f3 (синий)
- **В работе**: #ff5722 (оранжевый)
- **Завершен**: #9c27b0 (фиолетовый)
- **Отложен**: #607d8b (серый)

## Функциональность

### Серийное производство
1. **Просмотр заказов**
   - Компактная таблица со всеми заказами
   - Поиск по номеру партии и названию
   - Фильтрация по статусам
   - Прогресс выполнения

2. **Создание заказа**
   - Модальное окно с формой
   - 3 обязательных поля
   - Выбор упаковок из справочника
   - Указание количества для каждой упаковки
   - Поиск по упаковкам

3. **Управление заказами**
   - Просмотр состава
   - Редактирование (если не в работе)
   - Утверждение
   - Отложение
   - Удаление

### Индивидуальное производство
1. **Создание заказа**
   - 3 поля в одну строку
   - Загрузка Excel файла
   - Drag & Drop поддержка
   - Предпросмотр загруженного файла

## API интеграция
